# S02 · IAM · AWS

**Tipo:** laboratorio de análisis; sin ejecución remota desde la academia.
**Nivel:** Senior Mode

## Resultado verificable
Reconstruir los permisos requeridos por el pipeline y contrastarlos con las acciones concedidas.

## Contexto y límites
- Trabaja únicamente en cuentas o proyectos propios y autorizados de AWS.
- Los eventos y registros presentados en la web son **sintéticos**.
- No copies credenciales, tokens ni datos de clientes a la aplicación.
- Si el ejercicio requiere infraestructura real, prepara un ambiente aislado con presupuesto y permisos mínimos.

## Investigación guiada
1. Confirma identidad, alcance y entorno antes de cualquier consulta.
2. Formula una hipótesis inicial a partir de las dos evidencias sintéticas.
3. Identifica una hipótesis alternativa que explique la misma señal.
4. Recopila evidencia que pueda falsar cada hipótesis.
5. Escoge mitigación reversible; define una medición de éxito.

## Comandos de **solo lectura** orientativos
No ejecutes comandos sobre producción sin aprobación. Sustituye cualquier marcador explícito.

### Eventos y métricas
```bash
aws cloudwatch list-metrics --namespace AWS/EC2
```
Encontrar las series de métricas disponibles sin modificar recursos.

### Seguridad de acceso
```bash
aws iam list-roles
```
Revisar límites de permisos sin suponer acceso administrador.

### Inventario de redes
```bash
aws ec2 describe-vpcs
```
Confirmar el alcance de la red consultada.
